# Native daily Esch capture adapter

Public destination: `src/mardorf_collector/m3_daily_native.py` with adjacent `_m3_native_range.py`, `_m3_ifs_contract.py` and `_m3_coordinate_guard.py` (first two original helpers unchanged). No private model paths, model coefficients, observations, fitter, scheduler, service or activation belongs to these files.

API:

```python
collect(output, init_day, publish_bytes=callback)
# or publish_file=callback; exactly one callback
```

`init_day` is a literal UTC date. The adapter attempts exactly the 17 native 00 UTC slots at leads 24,30,...120 h. Target is AWEKAS Esch 52.269502777777774 N / 8.673894444444445 E, not substituted Rathaus geometry. `output` is a dedicated staging directory. Callbacks receive `(flat_name, bytes)` or `(flat_name, Path)` and **must complete immutable OVH publication plus full readback** before returning the exact `{'file','bytes','sha256'}` CAS reference. The adapter checks content size/hash, then removes its own local staging and fsyncs the directory. A callback failure leaves staging intact; an orchestration retry must use a new owned attempt directory, never overwrite an earlier attempt. `result.artifacts` preserves references to all successfully published raw/receipt/proof artifacts, including partial attempts.

Return: `{'result': capture_result_dict, 'receipt': result_CAS, 'input': input_CAS}`. Input schema `m3-frozen-native-forecast-input-v1` matches the frozen numerical adapter. Complete future pairs only enter input records; all 17 attempted leads remain in the result ledger. A missing source/field/member is a missing slot, never imputed. `result.raw_ifs_records` also preserves every source-bound IFS row independently of GEFS availability; it is a weather-only RAW context, not added to strict paired model input. Every valid time equals initialization+native lead; IFS and GEFS identities must match exactly. No time interpolation. GEFS supplies individual signed U/V components for all 31 members; individual magnitudes are computed by the unchanged numerical kernel.

GEFS uses existing Dynamical dataset v0.2.0 Icechunk source, immutable observed snapshot ID, selected native 0.25-degree four-cell subset, exact native sharding layout and original bounded-range wrapper. Full weather-shard reads are forbidden at store boundary. The additional inner coordinate guard bounds every metadata/coordinate transfer to a 4 MiB probe before return. Coordinate chunks are denied until their actual immutable v3 metadata (including consolidated root metadata) admits numeric dtype and lossless bytes/zstd codec. Before any coordinate decode it charges 2×max(full-array decoded bytes, native-chunk decoded bytes) for each coordinate, jointly at most128 MiB of the existing256 MiB design; this covers eager Xarray index allocation plus decode/cache copy. Changed/oversized layouts fail closed before any coordinate GET. Actual store handling of capped range requests remains a live deployment check. Expected decoded inner chunk is 2,158,592 B per component; admission rechecks this before weather `.load()`. Request limits retain the existing 8 MiB total weather payload / 8 requests, individual range 2,224,128 B and suffix 65,536 B. Peak design is 256 MiB, **not a measured runtime peak**. Runtime compatibility and actual available-memory admission remain the independent caller's responsibility. Any changed native layout/codec must be requalified before weather access.

IFS requests individual exact HTTP ranges from the existing ECMWF public AWS source, rejects a full HTTP 200 response to a range **before reading the body**, preserves raw messages and HTTP receipt clocks, and requires the original five native fields (`10u`,`10v`,`2t`,`sp`,`msl`). All mandatory fields and leads share exact native generation headers. Optional `2d`,`tcc`,`tp`,`10fg` are retained as raw channels only with explicit units, native interval and vertical operator; unsupported/failed optional decoding preserves raw artifacts and unqualified status instead of erasing mandatory wind. Surface pressure is native model-surface pressure, never relabelled absolute Esch/Rathaus station pressure.

`qualified=true` in the GEFS numerical input means finite exact native component/member/geometry layout, **not scientific generation-transfer acceptance**. Every result and source proof retains generation-transfer false. A separately reviewed input-admission producer must cross-check actual raw hashes, snapshot/header identities, chronology, source generation, native geometry/operators and exact candidate policy before inference. Publication, operational scheduling, full 17-slot cohort commitment, issue/known-by/fsync-before-valid, prospective T0, replay and report use belong to the controller. Source and runtime freezes must be checked before imports. No model inference or scoring occurs here.

Tests: `cd .../collector && python -m unittest -v test_m3_daily_native.py` (20 PASS locally). Tests use only synthetic metadata, raw/mock transport and temporary archives; no real providers or historical truth/model banks. Live decoder/store interoperability remains a deployment acceptance check. Helper original byte/body references are in `HELPER_BINDING.json`.
