# WP15-I02 native model intake, protocol V1

Existing acquisitions retain their actual HTTP responses and the successful ECMWF assembled SDK target before deletion. The V2 router attaches named shared and local sessions; requests is never patched. Provider cycle gates, request selections, optional stages, timeouts and workflow controls remain unchanged. The explicit layout successor V7 preserves its V6 validator, workflows and provider-session predecessors. The three protected provider sources and bridges remain byte-identical.

The parent protocol stores ordered 8 MiB chunks with a small manifest binding the whole original SHA-256, size, actual origin, acquisition model/stage, capture clock and producer commit. HTTP remains bounded at 512 MiB; the explicit SDK-target successor permits 2 GiB. Qualification permits 1 GiB decompressed per parent, 65,536 messages per parent, 16 GiB originals and 1,048,576 fields per delivery. Compact native/Parquet fragments remain below 8 MiB. Frozen WP13 8 MiB raw / 32 MiB decoded / 4,096-field contracts are unchanged.

Qualification reads actual GRIB headers and native nearest-point values. It checks provider centre, available request/run clocks, native validity, units, grid identity and member metadata. Original parameters and headers are retained, including unknown quantities. Unstructured native EPS grids retain their headers with `external_native_grid_definition_required`; they do not claim a point extraction. The already acquired EPS API response separately preserves its actual returned point, member-zero semantics, native arrays and units. Its stable bracketed provider-cycle/spatial evidence is stored once; no initialization clock is invented inside a response which does not embed one.

Original objects, extracts, projections, cycle evidence and catalog are immutable. Publication performs a complete B2 cold readback before one ingress marker becomes visible via the existing control-head CAS. Private admission loads the exact reader release, independently audits every original and compares saved native records against Parquet, then publishes one immutable acceptance receipt. Retries reuse accepted deliveries. Capture storage errors block native admission and preserve valid legacy provider bodies.

ModelReader queries native quantities by parameter, model, validity and member from compact extracts without fetching original chunks. Full original audits are explicit; projection comparison streams bounded fragments. No normalization, interpolation, fits, model voting or scientific release is performed. The scientific gate remains OPEN. Scheduled acquisition and the existing private native-stage runner use the same protocol; manual canaries retain their prior isolation.

Local validation: 436 collector tests and the package/workflow layout gate pass. Production acceptance is recorded in the private project audit, after real acquisition, B2 readback, private intake and forecast evidence. This document alone is not an acceptance claim.
