# Public ten-year station packages

`station-archive-packages.yml` prepares the registered four stations and ten hourly DWD products for 2016–2025. An optional single station/year scope is the pilot/recovery route. The matrix contains at most 40 station/year jobs, eight concurrent jobs and two separate product processes each. Products and complete station/year packages are immutable, hash-addressed B2 checkpoints; replay retains their original public verification times. Months without source rows are explicitly `VERIFIED_EMPTY`, never imputed. Braunschweig solar remains original-only.

The package namespace is separate from I05 monthly publications, so the routine orphan reconciler does not create 4,800 individual private admissions. Intermediate progress does not advance the private GitHub head. The existing 2016 Soltau wind checkpoints are read only and their manifests and clocks are reused. ZIP originals, source values, missingness, units, quality flags and source positions use the accepted I05 validation/normalization and unchanged long Parquet schema.

The consumer must first deploy an exact package engine/contract readiness record. A public release is sealed only after every requested station/year has all ten products and twelve month states. Privatization verifies the release and inline monthly manifests, writes actual private package receipts and advances one atomic accepted index. It never downloads provider archives or normalizes rows. A failed private commit leaves immutable receipts which replay reuses; queries retain prior individually admitted clocks for identical publications. Disabling the consumer revokes readiness and leaves checkpoints intact.

Operational runtime observations are nonblocking. GitHub job timeouts provide a hard upper bound; interrupted jobs resume product and monthly objects. Import acceptance additionally checks cold native/projection/physical readback, source completeness, causal clocks and the preserved I03 cohort and fits. Science remains OPEN; no new wind, calibration or forecast analysis is enabled.
